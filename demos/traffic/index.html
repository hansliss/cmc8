CMC8 traffic lights

The original 75-byte program controls the signals. Side-road cars arrive every 75 simulated seconds on average across both approaches and activate the sensors. One simulated second follows the original Midahs clock.

Instruction-level demo: uses a shared CPU core with program memory, ED4 lamps and T1/T3 sensors attached; interrupts and external handshaking are not modeled. Replacement programs use the same ED4 lamps and T1/T3 sensors. Yellow holds arriving cars; cars already in the junction continue through.
