Try it

Press GO to run the default switches-to-lamps program. Toggle the eight switches. Press KEX to return to the monitor.

In AD mode, enter four octal digits: page followed by a three-digit address. For example, 0 0 0 0 selects page 0, address 000. Press + to examine successive bytes. Press DA, then three octal digits to replace a byte; the write updates with each digit. Press AD to return to address entry. Two consecutive presses of AD cycle the selected memory space P → S → E.

Keyboard shortcuts: digits 0–7, Enter for GO, A for AD, D for DA, +, and Escape for KEX. Hold/release is modeled; the monitor acts on release. Page 3 is read-only monitor ROM. GO uses program memory regardless of the examination space; addresses 2,316–317 octal are reserved for its jump stub.

Functional reconstruction, not an original KEX ROM dump. CPU inspection shows instruction boundaries, not live signal timing. Implementation and research notes · Traffic demo
